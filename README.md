# WayScanner

위험 구역을 피해 이동하는 자율주행 로봇의 Pygame 시뮬레이터.

지진, 화재, 방사능 지점이 있는 2D 격자 지도에서 로봇이 일반 장애물과 진입 금지 구역을 피해 최단 경로로 이동한다. 이동 거리와 방향 전환 횟수를 화면에 표시한다.

## 한 줄 정의

흩어진 위험 점을 하나의 금지 구역으로 묶고, 그 구역과 일반 장애물을 피해 목적지로 가는 최단 경로를 찾는다.

## 핵심 기능

위험 구역을 계산한 뒤, 그 결과를 사용해 경로를 탐색한다.

| 순서 | 기능 | 핵심 아이디어 | 담당 |
| --- | --- | --- | --- |
| 1 | 위험 구역 설정 | 위험 점들의 가장 바깥을 잇는 최소 볼록 다각형(Convex Hull, Graham Scan) | 팀원 |
| 2 | 최적 회피 경로 탐색 | 일반 장애물과 위험 구역을 함께 우회하는 최단 경로(A*) | 본인 |

## 유기적 작동

1. 지도 위에 지진, 화재, 방사능 같은 위험 점이 무작위로 생긴다.
2. 그 점들을 하나의 Keep-out Zone(진입 금지 구역)으로 묶는다. 로봇은 이 다각형의 내부와 경계를 통과하지 않는다.
3. 출발지에서 목적지까지, 일반 장애물과 금지 구역을 동시에 피하는 경로를 찾는다.
4. 확정된 경로에서 총 이동 거리와 방향 전환 횟수를 뽑는다.
5. Pygame 화면에서 경로를 따라 움직이는 로봇과 주행 진행률을 보여 준다.

자세한 합의 내용은 [docs/concept.md](docs/concept.md)에 있다.

## 현재 상태

- `hazard_zone.py`는 위험 점을 검증·중복 제거하고 Graham Scan으로 금지 다각형을 만든다.
- `pathfinder.py`는 네 방향 이동 A* 경로를 찾고 거리·회전 수를 계산한다.
- `main.py`는 Pygame 격자 시뮬레이터 실행 파일이다.

## 실행

Python으로 다음 명령을 실행한다. 화면에 한글을 표시하려면 맑은 고딕, Noto Sans CJK KR, 나눔고딕 또는 AppleGothic이 설치되어 있어야 한다.

```bash
python -m pip install -r requirements.txt
python main.py
```

**경로 찾기**를 누르면 최단 경로가 표시된다. **주행 시작**으로 이동을 재생하고 일시 정지하거나 1×·2×·4× 속도로 볼 수 있다. **새 지도**는 위험 지점과 장애물 배치를 다시 생성한다.
