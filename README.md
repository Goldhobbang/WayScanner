# WayScanner

Python과 Pygame으로 만든 로봇 경로 찾기 프로그램입니다.
지도에 있는 장애물과 위험 구역을 피해서 목적지까지 이동하는 모습을 볼 수 있습니다.

## 기능

- 위험 지점들을 묶어서 로봇이 들어가지 못하는 구역을 만듭니다.
- A* 알고리즘으로 경로를 찾습니다. 언덕은 높을수록 이동 비용이 커집니다.
- 이동 거리와 방향을 바꾼 횟수를 보여줍니다.

## 실행 방법

Python을 설치한 뒤 프로젝트 폴더에서 아래 명령어를 실행하면 됩니다.

```bash
python -m pip install -r requirements.txt
python main.py
```

실행 후 `경로 찾기`를 누르고 `주행 시작`을 누르면 로봇이 움직입니다.
`새 지도`를 누르면 지도를 다시 만들 수 있고, `+`, `−` 버튼으로 언덕 개수를 바꿀 수 있습니다.

## 파일 설명

- `main.py`: 화면 표시와 로봇 이동
- `hazard_zone.py`: 위험 구역 만들기
- `pathfinder.py`: 경로 찾기
