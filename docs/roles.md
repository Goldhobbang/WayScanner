# 역할

이름 대신 역할로 적는다. 저장소를 같이 쓰는 사람이 늘면 이 표에 이름만 보탠다.

| 역할 | 맡는 일 | 맡지 않는 일 |
| --- | --- | --- |
| 팀원 | 위험 점을 볼록 금지 구역으로 묶는 일 (Convex Hull, Graham Scan) | 경로 비용 정의, 배터리 모델 학습 |
| 본인 | 금지 구역과 장애물을 우회하는 경로 탐색 (A*), 경로 특징값으로 잔량을 예측하는 일 (선형 회귀) | 위험 구역의 모양을 임의로 단순화하는 일 |

"본인"은 이 저장소에서 경로와 배터리 두 기능을 맡기로 한 쪽이다.

## 같이 정해야 하는 것

구현을 시작하기 전에 아래만 합의하면 각자 진행할 수 있다.

1. 격자에서 한 칸의 의미와, 칸 사이를 어떻게 이동하는지 (상하좌우만인지, 대각 포함인지)
2. 금지 다각형의 경계 칸을 통과 불가로 볼지
3. 위험 점이 2개 이하일 때 경로 모듈이 받을 값
4. "총 이동 거리"와 "방향 전환"을 세는 규칙
5. 초기 배터리와 잔량(%)의 의미

1~3은 팀원과 본인이 함께, 4~5는 본인 쪽에서 초안을 내고 팀원이 경로 결과와 맞는지 확인한다.

## 협업 시 지킬 것

- 다른 담당 모듈의 내부 계산을 대신 고치지 않는다. 인터페이스(주고받는 값)가 바뀌면 먼저 적고 공유한다.
- 경로가 없을 때 잔량을 임의 숫자로 채우지 않는다.
- 위험 구역을 "대충 사각형"으로 대체하지 않는다. 합의된 형태는 위험 점을 모두 포함하는 최소 볼록 다각형이다.
- 이 저장소의 기초 문서와 다른 동작을 넣으면, 코드를 올리기 전에 해당 문서를 먼저 고친다.
