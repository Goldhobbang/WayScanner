# 이후 진행

구현과 문서는 같은 규칙을 유지한다. 합의가 달라지면 관련 모듈과 문서를 함께 갱신한다. 날짜는 아직 없다.

## 지금

- 위험 구역 모듈의 Graham Scan과 내부·경계 판정이 구현되어 있다.
- 경로 모듈의 네 방향 A* 구현과 거리·회전 계산이 있다.
- `main.py`에서 격자 시뮬레이터를 실행할 수 있다.
- 학습된 배터리 모델과 학습 데이터는 아직 없다.

## 다음

1. 위험 구역 모듈의 점 목록과 꼭짓점 결과를 작은 예시로 문서화한다.
2. 경로 모듈과 위험 구역 모듈을 연결해 경로 및 두 특징값의 예시를 확인한다.
3. 초기 배터리 기준과 학습 데이터 출처를 정한 뒤, 배터리 예측 모듈을 구현한다.
4. 화면에 구역, 경로, 잔량 또는 예측 불가 표시를 함께 보여 준다.

## 일부러 뒤로 미룬 것

- 위험 종류마다 다른 비용
- 잔량이 부족할 때 경로를 다시 고르는 일
- 움직이는 장애물, 센서 오차, 여러 로봇
- 배포와 설치 방법

미룬 항목을 앞에 넣고 싶으면 roadmap을 먼저 고치고 구현한다.
