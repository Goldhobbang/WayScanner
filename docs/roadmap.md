# 이후 진행

코드는 이 문서가 맞고, 역할 문서의 "같이 정해야 하는 것"이 합의된 뒤에 올린다. 날짜는 아직 없다.

## 지금

- 저장소와 기초 문서만 있다.
- 구현, 의존성, 화면, 학습 데이터는 없다.

## 다음

1. 격자 이동 규칙과 거리·회전 정의를 문서로 확정한다. 금지 다각형은 내부와 경계 모두 통과 불가로 합의했다.
2. 위험 구역 모듈이 점 목록을 다각형 꼭짓점으로 바꾸는 계약을 작은 예시(점 좌표와 기대 꼭짓점)로 적는다. 예시는 설명용 숫자만 두고, 계산 절차는 적지 않는다.
3. 경로 모듈이 그 다각형을 통과 불가로 보고 경로와 두 특징값을 내는지 같은 예시로 확인한다.
4. 배터리 모듈이 그 두 값만으로 잔량(%)을 내는지 확인한다. 학습 데이터 출처가 정해지기 전에는 예측 숫자를 확정값처럼 적지 않는다.
5. 세 결과가 한 화면에 같이 보이는지 확인한다.

## 일부러 뒤로 미룬 것

- 위험 종류마다 다른 비용
- 잔량이 부족할 때 경로를 다시 고르는 일
- 움직이는 장애물, 센서 오차, 여러 로봇
- 배포와 설치 방법

미룬 항목을 앞에 넣고 싶으면 roadmap을 먼저 고치고 구현한다.
