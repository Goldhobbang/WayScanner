# 용어

프로젝트 안에서 아래 뜻으로만 쓴다. 비슷한 말을 섞지 않는다.

| 용어 | 뜻 |
| --- | --- |
| 격자 지도 | 로봇이 칸 단위로 움직이는 2차원 맵 |
| 일반 장애물 | 위험 점과 무관하게 처음부터 지나갈 수 없는 칸 |
| 위험 점 | 지진, 화재, 방사능 등 무작위로 생기는 위험 위치. 그 자체는 아직 구역이 아니다 |
| 위험 구역 / 금지 구역 / Keep-out Zone | 위험 점 전부를 포함하는 최소 볼록 다각형의 내부와 경계. 로봇이 들어가거나 지나가지 않는다 |
| Convex Hull | 점들을 모두 담는 가장 작은 볼록 다각형 |
| Graham Scan | 그 볼록 다각형을 구하는 방법으로, 이 프로젝트에서 쓰기로 한 이름 |
| 볼록 | 다각형 안의 어떤 두 점을 잇는 선도 다각형 밖으로 나가지 않음. 오목하게 들어가지 않음 |
| A* | 실제 비용 `g(n)`과 예상 거리 `h(n)`을 더해 경로를 고르는 탐색 |
| `g(n)` | 출발지에서 현재 위치까지 실제로 들인 이동 비용 |
| `h(n)` | 현재 위치에서 목적지까지의 예상 거리. 실제보다 과대하면 최단을 보장하지 못한다 |
| `f(n)` | `g(n) + h(n)`. 다음에 볼 위치를 고를 때 쓰는 평가값 |
| 회피 경로 | 일반 장애물과 금지 구역을 모두 피한 출발지–목적지 칸 순서 |
| 총 이동 거리 | 확정된 경로에서 이동한 칸 수 |
| 방향 전환 / 회전 | 경로에서 진행 방향이 바뀐 횟수 |
| 특징값 (feature) | 배터리 모델에 넣는 입력. 지금은 총 이동 거리와 회전 횟수 둘뿐이다 |
| 선형 회귀 | 두 특징값으로 잔량을 직선 관계로 예측하는 모델. 시뮬레이터 안에서는 학습하지 않고 예측만 한다 |
| 예상 배터리 잔량 | 목적지 도착 시점에 남아 있을 것으로 예측한 배터리 비율(%) |
| 실시간 예측 | 경로가 새로 확정될 때마다 잔량을 다시 계산해 화면에 내는 것 |

쓰지 않기로 한 말:

- "위험 반경": 점 주변 원으로 막는 방식은 이번 합의가 아니다.
- "최단"을 금지 구역을 무시한 직선 거리에 쓰지 않는다. 최단은 항상 회피 이후의 경로를 말한다.
